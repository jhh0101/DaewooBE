# Hotel Reservation Web

Spring Boot 기반 호텔 예약 웹 4인 프로젝트입니다.

## 개발 목적
- Spring Boot 기반 CRUD 및 예약 시스템 구현 학습
- 사용자 예약 흐름 및 결제 검증 로직 경험
- 팀 프로젝트 기반 협업 경험

## 주요 기능
- 회원가입 / 로그인
- 호텔 예약
- 결제 금액 검증
- 관리자 페이지
- 동적 검색 기능

## 기술 스택
- Java
- Spring Boot
- JPA
- MySQL
- React

## 프로젝트 회고
프로젝트 초기에는 기능 구현 중심으로 개발을 진행했으며, 이후 조회 성능 문제(N+1), API 스펙 관리, 예외 처리 구조 등의 중요성을 체감했습니다. 이후 개인 프로젝트에서는 구조 개선과 검증 방식에 더욱 신경 쓰게 되는 계기가 되었습니다.
